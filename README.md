# Churn Analysis and Customer Intelligence

An end-to-end churn analysis for an OTT subscription platform, built with Python and SQL. It shows how many customers leave, what that costs in revenue, and which customers to save first.

## What this project covers

- **Churn and revenue impact:** measures the churn rate and its effect on Monthly Recurring Revenue (MRR) and Customer Lifetime Value (CLTV).
- **Risk scoring and segmentation:** scores customers by likelihood to churn and groups them into segments, so retention effort goes to the highest-risk, highest-value customers.
- **Support and cancellation analysis:** looks at how support interactions and cancellation reasons relate to churn.
- **Retention recommendations:** turns the findings into specific actions the business can take.
